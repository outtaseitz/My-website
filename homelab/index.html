Overview

My homelab is a hands-on environment where I design, deploy, and troubleshoot infrastructure similar to what is used in small business IT environments. It includes virtualization, firewall routing, VLAN segmentation, Docker services, storage, monitoring, remote access, DNS filtering, VPN routing, and automation projects.

Proxmox OPNsense Docker Cloudflare TrueNAS Grafana Power BI n8n

Core Infrastructure

  • Multi-node Proxmox virtualization cluster
  • OPNsense firewall/router with VLAN segmentation
  • UniFi wireless with multiple SSIDs mapped to VLANs
  • Cisco managed switch for trunking and PoE
  • TrueNAS storage for shared data and services

Networking

  • Separate VLANs for home, servers, IoT, and tunnel services
  • Firewall rules for isolation and controlled access
  • Pi-hole and Unbound DNS filtering/resolution
  • Cloudflare Tunnel for secure external access
  • VPN routing experiments with NordVPN, Mullvad, WireGuard, and Gluetun

Identity & Endpoint Administration

  • Run a Windows Server domain controller for hands-on Active Directory practice
  • Manage user accounts, groups, permissions, and domain-joined devices
  • Use Microsoft Entra ID tenant for cloud identity and Microsoft 365 administration learning
  • Administer family devices, including kids' Windows PCs, policies, access, and account controls
  • Practice real-world concepts like least privilege, password management, remote access, and device lifecycle support

Self-Hosted Services

  • Jellyfin media server with supporting automation tools
  • Sonarr, Radarr, Prowlarr, qBittorrent, and Gluetun
  • Nextcloud for private file access
  • Guacamole for browser-based remote access
  • Mealie, ntfy, Homepage, Portainer, and other utility services

Monitoring & Reliability

  • Prometheus and Grafana dashboards
  • Node Exporter and cAdvisor metrics
  • Gateway monitoring and packet-loss troubleshooting
  • Service health checks and notification workflows
  • Hands-on troubleshooting of modem, routing, DNS, and VLAN issues

Automation & Data Projects

M3 / Power BI Proof of Concept

Built a proof-of-concept pipeline using FastAPI, PostgreSQL, n8n, Grafana, and Power BI concepts to model shipment forecasting data.

Workflow Automation

Used n8n webhooks and function nodes to receive, transform, store, and query operational data.

Notification Systems

Connected self-hosted services to ntfy for request alerts, service checks, and operational notifications.
